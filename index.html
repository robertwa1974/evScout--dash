Scout 80 Dash

Web Installer — Waveshare ESP32-S3-Touch-LCD-7 · v2.3

1 What you need

  • Waveshare ESP32-S3-Touch-LCD-7 and a USB-C cable that supports data transfer (charge-only cables won't connect)
  • Google Chrome or Microsoft Edge on a computer (Firefox and Safari don't support Web Serial)
  • On Windows, the CH343 USB-serial driver if the board doesn't show up as a COM port
⚠️ Set the board's UART DIP switch to USB before connecting. The GPS module shares the same serial port, so the installer can't reach the chip with the switch on GPS.

2 Install firmware

⚠️ Your browser doesn't support Web Serial.
Please use Chrome or Edge. Click to Install Scout 80 Dash

Pick the board's serial port when asked. Installing takes about a minute.

Updating a dash you already use? Leave "Erase device" unticked. Your settings, speed calibration and odometer are kept.
⚠️ "Erase device" wipes everything stored on the board: warning thresholds, display settings, speed calibration, the odometer and the CAN baseline. Only tick it for a new board or to recover from a bad install. The SD card is not affected.

3 After installing

  • Set the UART DIP switch back to GPS, or the GPS module won't be read
  • The dash restarts to the Scout splash screen, then the Speed screen
  • Check the version under Settings ("Firmware: …")
Once the dash is installed in the truck, you can update it without USB: turn on Settings › Display › WiFi Config, join Scout80-Config, open http://192.168.4.1/update and upload firmware.bin from the latest release.
